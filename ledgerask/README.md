# LedgerAsk 公开展示页

静态 HTML、CSS 和 JavaScript，发布到 <https://sleepinwei.github.io/ledgerask/>。展示主应用已实现的核心功能，不连接业务 API，不收集访客数据，不包含供应商密钥或原始测试文件。

## 本地预览

在本目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。视频使用 MP4/H.264，中文解说、字幕与章节通过本地资源提供。

## 发布边界

- 仅将本目录的发布文件复制到 `SleepinWei/SleepinWei.github.io` 的 `ledgerask/`；保留现有站点其它内容。
- 主应用仓库保持私有，不复制应用代码、环境文件、Git 历史、原始 PDF、认证状态、私有日志或原始录像。
- 演示连接隔离的真实 API/数据库。样本根据本地 `test_data` 文件类型与结构脱敏重建，企业身份、账号、税号、编号、金额、签章、图片及元数据不可逆移除或替换；公开数值为虚构。
- 所有公开视频帧与截图必须只来自隔离演示租户。不得用模糊或可移除的网页 CSS 遮挡作为最终脱敏。
- 等待过程允许剪辑，不能将视频时长用作处理性能或质量承诺。

更新资产后检查引用路径、移动端布局、键盘操作、章节跳转、字幕以及公开 payload 文件清单；发布后检查 GitHub Pages 构建和公开 URL。
